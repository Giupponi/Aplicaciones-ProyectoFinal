# Blue Whales — Manual de Instrucciones y Documentación Técnica

## 1. Descripción

**Blue Whales** es una aplicación móvil desarrollada con **React Native**, **TypeScript** y **Expo**. Su propósito es permitir a los usuarios gestionar su colección personal de videojuegos, seguir estadísticas de juego en tiempo real y personalizar su perfil utilizando la cámara nativa del celular.

---

## 2. Requisitos e Instalación

### Requisitos Previos

* Node.js (v18 o superior)
* Aplicación **Expo Go** instalada en el celular (Android / iOS) o emulador configurado.

### Guía de Instalación y Ejecución

1. Clonar el repositorio
   git clone <URL_DEL_REPOSITORIO>

2. Acceder al directorio e instalar dependencias
   cd ProyectoFinalApp
   npm install

3. Iniciar el servidor de desarrollo de Expo
   npx expo start

Escanear el código QR resultante desde la app **Expo Go** en el celular.

Esperar la descarga de todos los elementos en el celular.

## Asistencia de Herramientas de IA

Durante la construcción del proyecto se utilizaron las siguientes herramientas de Inteligencia Artificial:

* **Gemini (NotebookLM)**: Guía de arquitectura móvil en React Native, depuración de errores de TypeScript/React Navigation e implementación de expo-image-picker y React Context.
* **Claude**: Asistencia en la sintaxis y secuencia de comandos de Git.
* **GitHub Copilot**: Soporte en la gestión del repositorio y organización de la rama principal (main) y ramas secundarias. Asi como tambien solucion de errores en las pantallas de login y registrar.
